# Agents Lab: Kraken

Multi-agent system for read-only diagnosis of a Kubernetes cluster via kubectl.

- `AGENTS.md` — instructions for the main agent Kraken (loaded automatically by GigaCode)
- `CLAUDE.md` — imports `AGENTS.md` (for Claude Code only)
- `agents/` — instructions for three subagents (Java app, Jenkins CI, Confluence)
- `config/repo-map.txt` — mapping of repository URL to local path
- `knowledge/` — knowledge files written by subagents (not committed)
- `FIRST-RUN-CHECKLIST.txt` — first-run checks

Before the first run, fill in the placeholders marked `<...>` (see the checklist).
